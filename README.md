# Al-Bawadi Digital Transformation Initiative

## Project Overview
A comprehensive technical project management initiative aimed at executing the digital transformation for Al-Bawadi. The project encompasses the development of multiple technical systems and services, including a Digital Asset Management System, an AR-enabled mobile application, a membership ticketing system, an administrative dashboard, and cloud database infrastructure[span_0](start_span)[span_0](end_span)[span_1](start_span)[span_1](end_span).
